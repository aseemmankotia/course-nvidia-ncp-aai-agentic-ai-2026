# Chapter 5 Lab: Task Decomposition and Memory Systems

**Estimated time:** 30 minutes

## Exercise

Implement a working-memory buffer with rolling summarization plus a long-term vector-store memory, and run an agent across a multi-turn task that requires recalling a fact from three sessions earlier

## Key takeaway

Choose memory type (short-term, long-term, episodic, semantic) and compaction strategy based on how long information must persist and how it will be recalled.
