# Chapter 4 Lab: Orchestration Frameworks and State Management

**Estimated time:** 35 minutes

## Exercise

Implement the same three-agent research workflow in CrewAI and in NVIDIA NeMo Agent toolkit side by side, comparing how each manages state and enforces termination

## Key takeaway

Framework choice depends on required control granularity (LangGraph), role simplicity (CrewAI), conversational flexibility (AutoGen), or native NVIDIA-stack integration (NeMo Agent toolkit).
