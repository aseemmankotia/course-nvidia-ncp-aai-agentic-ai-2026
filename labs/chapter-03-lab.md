# Chapter 3 Lab: Multi-Agent Coordination Patterns

**Estimated time:** 35 minutes

## Exercise

Build a supervisor/worker multi-agent graph in LangGraph with a router node that delegates to a research-worker agent and a writing-worker agent, sharing state via a typed graph state object

## Key takeaway

Pick the coordination pattern — supervisor/worker, hierarchical, sequential, or collaborative — based on how the described workflow's tasks actually depend on each other.
