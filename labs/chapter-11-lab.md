# Chapter 11 Lab: Guardrails, Security, and Responsible Deployment

**Estimated time:** 30 minutes

## Exercise

Configure input/output filtering rails plus a human-in-the-loop approval gate in front of a high-risk tool call (e.g., a financial-transaction agent) and verify a blocked action is logged for audit

## Key takeaway

Layer input/output guardrails, human-in-the-loop gates for high-risk actions, and hard permission boundaries — no single control fully mitigates prompt injection or tool misuse.
