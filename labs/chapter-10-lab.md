# Chapter 10 Lab: Evaluating Agentic Systems

**Estimated time:** 30 minutes

## Exercise

Build an evaluation harness that scores an agent's final answer (task-completion) and its intermediate tool-call sequence (trajectory) using an LLM-as-judge rubric across a fixed benchmark set of multi-step tasks

## Key takeaway

Evaluate agents on both task-completion and trajectory, using rubric-based LLM-as-judge scoring to handle non-determinism reliably.
