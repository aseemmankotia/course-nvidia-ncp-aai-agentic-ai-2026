# Chapter 7 Lab: Tool Integration, APIs, and the Model Context Protocol

**Estimated time:** 30 minutes

## Exercise

Wire an MCP server exposing a database-query tool and a sandboxed code-execution tool to an agent; add retry-with-backoff and idempotency keys for a payment-like tool call

## Key takeaway

Safe tool integration requires schema validation, least-privilege permissioning, and idempotent, retry-safe execution — not just the ability to call the tool.
