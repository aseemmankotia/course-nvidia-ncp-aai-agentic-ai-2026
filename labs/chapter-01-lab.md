# Chapter 1 Lab: Anatomy of an LLM Agent

**Estimated time:** 30 minutes

## Exercise

Build a minimal ReAct agent in Python against an NVIDIA NIM-hosted LLM endpoint that reasons, calls a calculator tool, observes the result, and reflects before answering

## Key takeaway

Match the reasoning pattern and agent count to the task's step count and coordination need — don't default to the most complex option.
